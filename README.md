## Estrutura
### Spring
#### Dependencias:
- Lombok
- Spring Web
- Spring Security
- Spring data JPA
- PostgreSQL Driver
- JJWT :: API, JJWT :: Impl, JJWT :: Extensions :: Jackson

## TASKS

- Configurações do Security
- Criar um POST (Cadastro usuario)
- Criar um GET (Buscar usuario)
- Criar um DELETE (Deletar um usuario)
- Criar um PUT (Alterar dados do usuario)
- Criar um PUT que altera dados de endereço (recebendo endereço_id) - incluir no DTO o retorno do id
- Adicionar o PUT que altera dados de telefone (recebendo telefone_id) - incluir no DTO o retorno do id
- Criar um POST exclusivo para endereços de usuários já cadastrados
- Criar um POST exclusivo para telefones de usuários já cadastrados
- Endpoint que verifica o JWT token pelo agendador
